O que me foi pedido nesse projeto do DataLab(DataCamp):

Realize uma análise exploratória de dados no arquivo netflix_data.csv para entender melhor os filmes da década de 1990.

Qual foi a duração de filme mais frequente nos anos 1990? Salve uma resposta aproximada como um inteiro chamado duration (use 1990 como o ano inicial da década).

Um filme é considerado curto se tiver menos de 90 minutos. Conte o número de filmes de ação curtos lançados nos anos 1990 e salve esse inteiro como short_movie_count.
